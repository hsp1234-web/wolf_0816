# 善狼計畫 (Wolf Project)

一個輕量化的 Web 應用程式，旨在提供一個穩定的介面來執行後端 AI/數據處理腳本。採用了以單體 FastAPI 伺服器為核心的極簡架構。

## 核心架構

- **`Colabpro.py`**: 專為 Google Colab 設計的一鍵啟動器，負責處理環境設定、依賴安裝及啟動後端伺服器。
- **`api_server_v2.py`**: 核心後端伺服器，提供 API 端點並服務前端介面。
- **`index.html`**: 由伺服器提供的單頁前端，使用者可透過此介面與後端互動。
- **`scripts/`**: 存放所有可獨立執行的後端工具腳本（如影片下載、報告生成等）。

## 如何啟動

1.  在 Google Colab 中打開 `Colabpro.py`。
2.  根據需求調整儲存格上方的參數。
3.  點擊「執行」按鈕。
4.  等待啟動器完成所有任務，並在下方提供公開的存取網址。
5.  點擊網址即可訪問操作介面。
