# 鳳凰音訊轉錄儀 (Phoenix Transcriber)

[![zh-Hant](https://img.shields.io/badge/language-繁體中文-blue.svg)](README.md)

這是一個高效、可擴展的音訊轉錄專案，旨在提供一個可以透過 Web 介面輕鬆操作的語音轉文字服務。專案前端已由**Vue.js**驅動，後端整合了 **YouTube 影片處理與 AI 分析** 功能。

## ⚡️ 如何啟動與測試

我們建議使用整合的啟動器腳本來進行開發與測試。

### 前置步驟：建置前端

在執行任何後端服務或測試之前，必須先建置 Vue.js 前端應用。

```bash
# 進入 vue-app 目錄
cd vue-app

# 安裝前端依賴
bun install

# 建置前端應用
bun run build

# 返回專案根目錄
cd ..
```

### 方式一：啟動本地開發伺服器

這是進行開發或手動測試時，最推薦的啟動方式。它會自動處理所有後端服務的啟動與監控。

**適用場景**：
*   本地前端開發，需要一個穩定運行的後端 API。
*   進行手動功能測試或 API 除錯。

**如何使用**:
```bash
# 此指令會安裝後端依賴、啟動服務，並持續運行
python3 runner/localrun.py
```
服務啟動後，腳本會顯示 API 伺服器的監聽位址。您可以按下 `Ctrl+C` 來隨時關閉所有服務。

### 方式二：執行自動化測試

此方式用於執行完整的自動化測試套件，包括後端單元測試和前端端對端 (E2E) 測試。

**適用場景**：
*   在提交程式碼變更前，驗證功能是否正常。
*   進行測試驅動開發 (TDD)。

**如何使用**:
```bash
# 此指令會安裝依賴、建置前端、啟動服務、執行測試，然後自動關閉
python3 runner/localtest.py
```
此腳本內建 **100 秒的超時機制**，以防止因服務關閉不穩定而導致的殭屍進程。
