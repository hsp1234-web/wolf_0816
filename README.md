# 鳳凰音訊轉錄儀 (Phoenix Transcriber)

[![zh-Hant](https://img.shields.io/badge/language-繁體中文-blue.svg)](README.md)

這是一個高效、可擴展的音訊轉錄專案，旨在提供一個可以透過 Web 介面輕鬆操作的語音轉文字服務。專案近期已整合 **YouTube 影片處理與 AI 分析** 功能。

## ⚡️ 如何啟動本地服務

我們建議使用整合的啟動器腳本來開始您的開發工作。

### 主要方式：使用本地開發啟動器 (推薦)

這是進行開發或手動測試時，最推薦的啟動方式。它會自動處理所有後端服務的啟動與監控。

**適用場景**：
*   本地前端開發，需要一個穩定運行的後端。
*   進行手動功能測試或 API 除錯。

**如何使用**:
```bash
# 此指令會安裝所有依賴、啟動服務，並持續運行
python3 runner/localrun.py
```
服務啟動後，腳本會顯示 API 伺服器的監聽位址。您可以按下 `Ctrl+C` 來隨時關閉所有服務。

此啟動器內建 **10 秒日誌看門狗**，如果服務在 10 秒內沒有任何活動，將會自動關閉，以防假死。更多技術細節，請參閱 **[`DOC/AGENTS.md`](./DOC/AGENTS.md)**。

---

### 次要方式：快速環境驗證

如果您只是想快速驗證本地環境（如 Python, Node.js）是否已正確設定，可以使用 `snapshot` 指令。

**注意**：此方式僅用於**一次性驗證**，它會啟動服務、執行一個簡單的測試、然後立即關閉，不適用於持續開發。

```bash
# 僅用於快速檢查環境配置
bun run snapshot
```
