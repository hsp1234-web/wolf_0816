# 前端 Vue.js 應用程式

本目錄 (`vue-app/`) 包含了「鳳凰音訊轉錄儀」專案的前端使用者介面。它是一個使用 **Vue 3** 和 **Vite** 建置的單頁應用程式 (SPA)。

## 在專案中的角色

此 Vue 應用並**不是**一個獨立的應用程式。它被設計為由專案根目錄的 Python 後端伺服器 (`src/api/api_server.py`) 來提供服務。

開發流程的核心是：
1.  在此目錄下修改 Vue 元件 (`.vue` 檔案)。
2.  執行建置指令，將所有前端資源打包到 `vue-app/dist/` 目錄。
3.  啟動 Python 後端伺服器，它會自動將 `dist/` 目錄作為靜態資源提供給瀏覽器。

**⚠️ 重要提示：** 請**不要**使用 `bun dev` 或 `vite` 指令來啟動本地開發伺服器，因為這會導致前端無法與後端 API 正常通訊。所有開發與測試都應透過專案根目錄的 `runner` 腳本來進行。

## 開發指令

所有指令都應在此 `vue-app/` 目錄下執行。

### 1. 安裝依賴

在開始前，或是在 `package.json` 有變動後，請執行此指令來安裝所有必要的 Node.js 套件。

```sh
bun install
```

### 2. 編譯與打包 (建置)

這是**最重要**的指令。每當您對前端程式碼 (`.js`, `.vue`, `.css` 檔案) 做出修改後，都必須執行此指令來讓變更生效。

```sh
bun run build
```
這個指令會讀取 `src/` 下的原始碼，並產生最佳化、壓縮後的版本到 `dist/` 目錄中。

### 3. 格式化與程式碼風格檢查

為了維持程式碼風格的一致性，您可以使用以下指令來自動格式化您的程式碼。

```sh
# 自動修正 ESLint 可以處理的問題
bun lint

# 使用 Prettier 格式化所有程式碼
bun run format
```

## 如何預覽您的變更

1.  在 `vue-app/` 目錄下，執行 `bun run build`。
2.  回到專案根目錄 (`cd ..`)。
3.  執行 `python3 runner/localrun.py` 來啟動後端伺服器。
4.  在瀏覽器中開啟腳本所提供的 URL (例如 `http://127.0.0.1:8001`)。
