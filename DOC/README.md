# 文件中心 (Documentation Center)

歡迎來到專案的文件中心。此目錄旨在集中管理所有與專案相關的技術文件、架構研究、開發計畫和歷史歸檔。

## 核心文件 (Key Documents)

以下是本專案最核心的幾份文件，建議新成員優先閱讀。

-   **`ARCHITECTURE_RESEARCH.md`**:
    -   **用途**: 本專案的**核心架構設計文件**。它詳細記錄了從初期研究到最終選擇 `Huey` + `SQLite` + `Circus` 技術棧的完整決策過程、方案比較和系統設計圖。所有重大的架構變更都應在此文件中體現。

-   **`plan.md`**:
    -   **用途**: **動態開發計畫與日誌**。它記錄了當前正在進行的開發任務、近期的架構決策摘要以及歷史開發紀錄。這是一個追蹤專案演進過程的「活文件」。

-   **`AGENTS.md`**:
    -   **用途**: **給 AI 開發者的說明文件**。這份文件提供了在此專案中進行開發與測試的具體流程和規範，例如如何建置前端、如何啟動不同模式的後端服務，以及如何執行自動化測試。

-   **`POST_MIGRATION_VERIFICATION.md`**:
    -   **用途**: **遷移後驗證手冊**。推測是用於在進行重大系統遷移或重構後，提供一份檢查清單和驗證步驟，以確保所有功能皆正常運作。

## 子目錄 (Subdirectories)

-   **`archive/`**:
    -   **用途**: **歷史文件封存區**。所有因技術迭代、方案變更而**過時**的研究報告、設計文件或舊的開發計畫，都會被加上封存標頭後移至此處。這裡的檔案不應再作為當前開發的參考，僅供歷史追溯之用。
