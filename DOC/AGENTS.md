# AGENTS.md - 給 AI Agent 的說明

歡迎，AI Agent！這份文件將幫助你了解如何在這個專案中工作。

## 專案結構

- `src/`: 核心應用程式原始碼。
- `runner/`: 包含用於執行測試或本地任務的啟動器腳本。
- `e2e_tests/`: 包含 Playwright 端對端測試案例。

## 如何啟動本地開發伺服器

為了進行開發或手動測試，你需要啟動後端服務。我們提供了一個為此優化的專用啟動器。

**重要說明**: `runner/localrun.py` 腳本的角色已經從「測試執行器」變更為「服務啟動器」。這麼做是為了讓開發者在端對端測試 (`e2e_tests/`) 不穩定或正在開發時，也能夠順利啟動後端環境。

**執行指令:**

```bash
python3 runner/localrun.py
```

**這個指令會做什麼？**

1.  **自動安裝依賴**:
    - 它會安裝 `requirements-server.txt` 中定義的 Python 套件。
    - 它會執行 `npx playwright install chromium` 來確保測試框架所需的瀏覽器已安裝。
2.  **啟動後端服務**: 它會以正確的順序啟動資料庫管理器 (`db/manager.py`) 和 API 伺服器 (`api/api_server.py`)。
3.  **監控與日誌**:
    - **日誌輸出**: 它會即時顯示來自後端服務的日誌，並為其加上 `[db_manager]` 或 `[api_server]` 的前綴以便區分。
    - **日誌看門狗**: 如果服務在 **10 秒** 內沒有任何新的日誌輸出，啟動器會判定服務無回應，並自動終止所有進程。
4.  **保持運行**: 服務啟動後，腳本會持續運行，直到你手動停止它。

**如何停止服務:**

在終端機中按下 `Ctrl+C`。啟動器會捕捉到這個信號，並優雅地關閉所有後端服務。

**在真實模式下運行:**

如果你需要連接真實的外部服務 (例如，不使用 mock transcriber)，可以加入 `--no-mock` 旗標：

```bash
python3 runner/localrun.py --no-mock
```
