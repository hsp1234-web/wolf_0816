# AGENTS.md - 給開發者的說明文件

歡迎！這份文件將幫助你了解如何在這個專案中進行開發與測試。

## 專案結構

- `src/`: 核心後端應用程式原始碼。
- `vue-app/`: 前端 Vue.js 應用程式原始碼。
- `runner/`: 包含用於執行測試或本地任務的啟動器腳本。
- `e2e_tests/`: 包含 Playwright 端對端測試案例。

## 開發與測試流程

### 前置步驟：建置前端資產

無論您選擇哪種後端模式，都**必須**先建置前端。此步驟會將 Vue.js 應用程式編譯為靜態檔案，以便後端伺服器能夠提供服務。

```bash
# 1. 進入前端目錄
cd vue-app
# 2. 安裝依賴
bun install
# 3. 建置專案
bun run build
# 4. 返回根目錄
cd ..
```

### 啟動開發環境 (兩種模式)

目前，專案的背景任務處理存在兩種架構。請根據您的需求選擇合適的啟動模式。

---

#### **模式 A (穩定版): 整合式 Worker**

此模式會啟動核心後端服務以及舊版的整合式背景工作者 (`src/tasks/worker.py`)。這是目前**最穩定**的運作方式，適合進行一般的前端開發或功能測試。

**✅ 適用場景:**
-   開發與 `run_*.py` 無關的前端功能。
-   驗證系統核心功能的穩定性。

**🚀 如何啟動:**
```bash
python3 runner/localrun.py
```
此指令會自動安裝依賴、啟動所有必要的服務（API 伺服器、資料庫管理器、舊版 Worker），並持續顯示日誌。

---

#### **模式 B (實驗性): 獨立 Workers**

此模式會啟動核心後端服務以及**新架構**的獨立背景工作者（`run_youtube_worker.py`, `run_transcription_worker.py` 等）。這是專案未來的發展方向，旨在提高系統的模組化和可擴展性。

**✅ 適用場景:**
-   開發或測試新的獨立工作者 (`run_*.py`)。
-   驗證新架構與前端的整合情況。
-   測試 `WORKER_MODE=new` 環境變數下的 API 行為。

**🚀 如何啟動:**
```bash
python3 runner/localrun_new.py
```
此指令會啟動與模式 A 相同的核心服務，但會用新版的獨立工作者**取代**舊版的 Worker。

---

### 執行自動化測試

如果您修改了程式碼，並希望在提交前驗證其正確性，請使用此模式。它會執行完整的測試套件，包括後端的單元測試和前端的端對端測試。

**執行指令:**
```bash
python3 runner/localtest.py
```

**這個指令會做什麼？**
1.  **自動安裝所有依賴**：包括後端 Python 套件和 Playwright 測試框架所需的瀏覽器。
2.  **啟動後端服務**：在強制模擬 (mock) 模式下啟動服務。
3.  **執行 Pytest**: 自動探索並執行 `e2e_tests/` 目錄下的所有測試案例。
4.  **自動關閉**：測試執行完畢後，會回報結果並自動關閉所有相關服務。
5.  **全局超時**: 整個腳本會在運行 **100 秒** 後自動終止，以防止意外的殭屍進程。
