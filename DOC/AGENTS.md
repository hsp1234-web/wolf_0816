# AGENTS.md - 給開發者的說明文件

歡迎！這份文件將幫助你了解如何在這個專案中進行開發與測試。

## 專案結構

- `src/`: 核心後端應用程式原始碼。
- `vue-app/`: 前端 Vue.js 應用程式原始碼。
- `runner/`: 包含用於執行測試或本地任務的啟動器腳本。
- `e2e_tests/`: 包含 Playwright 端對端測試案例。

## 開發與測試流程

本專案的前後端是分離的。後端由 Python (FastAPI) 撰寫，前端由 Vue.js 撰寫。在執行任何操作前，請務必先建置前端。

### 步驟一：建置前端 (必要前置步驟)

無論您是要啟動本地開發伺服器，還是要執行自動化測試，都**必須**先建置前端。這會將 `vue-app/` 中的原始碼編譯打包，並放入後端伺服器能夠讀取的 `vue-app/dist/` 目錄中。

```bash
# 1. 進入前端應用程式目錄
cd vue-app

# 2. 安裝依賴
bun install

# 3. 執行建置
bun run build

# 4. 回到專案根目錄
cd ..
```
若未執行此步驟，您將無法在瀏覽器中看到前端介面，且端對端測試也會因頁面無法載入而失敗。

### 步驟二 (選項 A)：啟動本地開發伺服器

如果您需要手動測試功能、進行 API 除錯，或是開發新的前端功能，請使用此模式。

**執行指令:**
```bash
python3 runner/localrun.py
```

**這個指令會做什麼？**
1.  **自動安裝後端依賴**：安裝 `requirements-server.txt` 中定義的 Python 套件。
2.  **啟動後端服務**: 它會以正確的順序啟動資料庫管理器和 API 伺服器。
3.  **監控與日誌**:
    - 它會即時顯示來自後端服務的日誌，並為其加上 `[db_manager]` 或 `[api_server]` 的前綴以便區分。
    - 內建超時機制以確保服務穩定。
4.  **保持運行**: 服務啟動後，腳本會持續運行，直到您按下 `Ctrl+C`。

### 步驟二 (選項 B)：執行自動化測試

如果您修改了程式碼，並希望在提交前驗證其正確性，請使用此模式。它會執行完整的測試套件，包括後端的單元測試和前端的端對端測試。

**執行指令:**
```bash
python3 runner/localtest.py
```

**這個指令會做什麼？**
1.  **自動安裝所有依賴**：包括後端 Python 套件和 Playwright 測試框架所需的瀏覽器。
2.  **啟動後端服務**：在強制模擬 (mock) 模式下啟動服務。
3.  **執行 Pytest**: 自動探索並執行 `e2e_tests/` 目錄下的所有測試案例。
4.  **自動關閉**：測試執行完畢後，會回報結果並自動關閉所有相關服務。
5.  **全局超時**: 整個腳本會在運行 **100 秒** 後自動終止，以防止意外的殭屍進程。
